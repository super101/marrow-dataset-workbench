# 新数据集入库标准 v1

## 1. 状态与放行

`provisional` 表示文件已整理但尚未被批准用于指定实验；不等于临床合格。入库报告分别记录技术完整性、来源使用依据、标签复核、分组可行性，不把其中一个通过当作全部通过。脚本审计不自动授予研究授权，也不自动宣称伦理批准。

允许完整复制待复核资料到受控本地工作区。以下问题阻断正式训练或比较：身份来源冲突、源副本哈希不一致、无法读取的必需文件、无定义编码、未解决的无效框、未明确的未知/忽略语义，以及缺少任务所需的数据使用依据。问题可通过有记录的修复、专家确认、限定任务范围或预先确定的排除决定解决；排除记录不删除原始数据。未知类别不能仅通过改名为背景来解除阻断。

训练放行记录至少包含：版本、字典版本、任务类别、问题处置、使用依据状态、分组范围、评估限制、决定人和日期。只有技术审计通过而身份缺失时，可在明确限制下开展探索实验，不能标记患者独立测试。

## 2. 来源登记

每次入库保存 `dataset_id`、原提供方或公开出处、获取日期、原版本、引用信息，以及研究/再分发/公开展示分别允许的范围。依据状态可为 `verified`、`pending`、`not_permitted`；对应文档保存于本地受控位置，公开报告仅记录可公开的摘要。记录是否曾用于训练、调参、标注模型或论文开发，不能把历史验证集重新命名为未见测试集。

不因数据来自医院就自行生成伦理号、许可或患者标识。真实身份表与去标识化研究 ID 的对应表单独受控保存；公开代码不包含它们。

## 3. 工作副本与版本

- 原始源不更名、不修订 XML、不删重复图；工作版本使用新的空目录，独立复制。
- 对源图、XML、字典和关系表保存 SHA-256；复制后复验。快照证实本次观察到的内容，不表示存储介质不可更改。
- 原始标签、规范标签、审核状态和每次修订原因均可追溯。坐标转换明确 VOC 原点与边界包含规则，避免仅凭格式名称假定坐标语义。
- 版本变更记录新增/移除对象、标签改变、身份补全、组变化、切分改变及受影响实验；保留前版，不就地覆盖。

## 4. 标签字典与标注规则

CSV 必需列为 `code,name,role`，编码按字符串读入；`role` 为：

| 角色 | 含义 | 训练前要求 |
|---|---|---|
| `cell` | 已定义且用于该任务的细胞类 | 医学定义及类合并依据明确 |
| `ignore` | 已知不参与监督的区域/对象 | 具体模型的损失和评估忽略行为已验证 |
| `unresolved` | 尚不能可靠解释的标注 | 人工复核并明确处置；不能直接训练 |

同一编码不得有冲突定义。规范映射之外保留原始名称。合并细类需要医学依据，不能仅为提高指标。没有字典定义的编码自动列入待解决清单。

在模型比较前固定以下规则：

- **边缘/截断**：保留并标记有效标注；是否纳入主任务、最小可见性与裁剪要求事先确定。不要仅因触边自动删除。
- **未标注对象**：确认标注是否穷尽；无法确认时记录完整性未知。检测模型会将未匹配区域作为背景，必须说明并制定完整复核或忽略策略。
- **争议对象**：保留争议、双人意见和最终裁定；允许未解决状态，不能伪装一致性。
- **极少类**：统计实例、图像和独立组数量。只在一个组出现的类别无法可靠估计跨组效果，不拆该组凑齐折。不以增强后的数量替代独立样本量。
- **预标注**：检测器/分类器仅给建议，记录模型版本与人工确认；模型输出不能自动充当外部测试真值。

## 5. 身份、关系与分组

建立图像—源图—玻片—患者—采集批次映射，未知字段留空，来源证据单独记录。患者 ID 优先；患者缺失而玻片齐全时按玻片并限定泛化范围。部分身份可用于约束，但不能推断其余患者已独立。

完全重复图的关系、已确认的同一源图、裁剪、增强、重叠视野与近重复图形成连通分量，必须同组。近重复候选和自动几何匹配还需复核；自动扫描没有发现候选不证明不存在重叠。重复图标注不一致需复核，不任意挑一份覆盖。

批次用于分布分析或预定义批次外测试；同批次不必等于同患者。编号/时间代理只作敏感性分析，不写入真实身份字段。模型跑完后不得根据性能移动组。

## 6. 切分和封存

先分组再切分，最后生成裁剪与增强。每个派生文件记录父图与来源版本并继承 split。独立工作副本、格式转换和扩增都不是新样本。

不硬套固定比例：先报告独立组数、逐类组覆盖、最大组及折可行性。可行时预定义三折外层分组、内层验证选参；所有方法使用相同切分。组数不足则报告不可可靠估计，不强行生成平衡结果。仅对最重要比较增加种子，提前记录预算。

测试清单、哈希和规则在调参前封存；不用于阈值选择、选择融合方式或决定类合并。实际读取/使用留日志；封存是流程约束，不等于操作系统访问限制。新版本影响测试样本或规则时，记录重评范围，不能继续宣称此前未见。

## 7. 入库交付及演示

最低交付：来源/使用范围状态、图像与对象清单、字典、哈希与复制校验、异常与重复候选、身份补全模板、处理记录、当前状态和阻断清单。分组清单与可行性报告在来源补全后另行生成。

本地浏览展示原图框叠加、类别与问题筛选，并区分文件数、独立图数、实例数和独立组数。未解决样本明显标识，界面不冒充临床诊断工具。对外演示默认使用合成图，真实图必须有展示依据；禁止随代码发布真实原图或身份清单。
