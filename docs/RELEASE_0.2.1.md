# 0.2.1：灵活复核与选填备注

“完成复核”改为一次点击保存并确认，无须勾选标注完整性、填写理由或清空问题备注。删除框直接软删除，可撤销；图像、问题、裁剪和删除说明均为选填。导入修复记录也允许不填备注。

复核状态与问题清单分别保留。已复核图可以仍有检查提示；软件不会据此自动宣称标注穷尽、医学正确或使用依据已核实。原图、原始编码与原始对象保留，修改历史自动记录，保存失败与版本冲突保护继续生效。

导出不再通过理由、完整性勾选或依据文本重复设置操作门槛。未记录的研究使用说明、完整性和坐标核对依据如实进入提示。已复核版选择已复核图，基础档可包含未复核图。有效框、已定义类别、文件完整性、固定分组划分及泄漏等技术检查继续执行；分类已复核版仍需选择裁剪纳入，多主对象裁剪暂缓分类输出。

公开合成演示同步使用直接完成复核流程。旧的 [0.2.0 发布记录](RELEASE_0.2.0.md)保留当时行为，当前操作以[使用手册](USER_GUIDE.md)为准。

验证：26 项自动化测试通过，前端 JavaScript 语法检查通过。Edge 浏览器使用临时合成数据验证了无勾选完成复核、保留问题备注、无弹窗删除、撤销后保存与重载、已复核检测训练包导出及公开演示；原图哈希保持一致，无页面脚本错误。具体数据用途与操作者流程由研究者及所属机构判断。
