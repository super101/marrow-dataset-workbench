# 首版发布与验收清单

本表是发布门槛，复选框不代表功能已经验收。维护者应在发布说明中记录所用提交、环境、实际通过项及限制。所有技术验证默认使用临时目录和合成资料。

## 安装与启动

- [ ] Python 3.11 与 3.12 新虚拟环境 `pip install -e .` 成功。
- [ ] Windows 启动器从含空格的目录启动；`.venv`、`py -3.11`、指定解释器路径可用，缺依赖时明确提示且不静默安装。
- [ ] `python -m workbench --help` 与 `marrow-workbench --help` 正常。
- [ ] 非 editable 的 wheel 安装包含 HTML/JS/CSS，离开源目录也能启动。
- [ ] 默认 workspace 位于仓库外，服务只监听 `127.0.0.1`。
- [ ] 合成演示与真实数据导入分离，演示不自动授权或扫描任何医院目录。

## 数据完整性与访问边界

- [ ] 合成源图/XML 导入前后逐字节不变，工作图像为独立复制而非硬链接。
- [ ] 缺图、缺 XML、损坏图、重复或冲突字典、未知编码产生可追踪问题。
- [ ] 源坐标 `zero` 与 `voc` 显式选择；边界和单像素框转换正确。
- [ ] 拒绝未登记目录、`..` 穿越、符号链接逃逸、覆盖原目录/已有版本。
- [ ] 写接口的同源/会话校验有效；恶意标签、备注、文件名和 XML 作为文本处理。
- [ ] 原始标签和对象可追溯，API 不泄露内部文件路径。

## 人工复核与持久化

- [ ] 移动、缩放、新增矩形框和改标签后保存原图坐标。
- [ ] 草稿重启后恢复；保存失败有状态，不能显示假成功。
- [ ] 撤销/重做、软删除原因和修改记录一致。
- [ ] 已确认图编辑后回退；映射/身份/划分变化使有关准备检查失效。
- [ ] 两标签页旧版本提交得到冲突提示，不静默覆盖。
- [ ] 无框图必须有可靠完整性依据，不能把丢失 XML 当负样本。
- [ ] 未知/ignore 对象不能仅删框后消除阻断；错误标注处置需要依据。

## 分组与训练输出

- [ ] 患者、玻片、来源引用、重复像素及确认关系的传递闭包同组。
- [ ] 批次不擅自等同患者；缺身份时不输出患者独立主张。
- [ ] 稀有类单组覆盖明确报告，不拆组；空集合或不可行划分阻断。
- [ ] 严格/基础档对相同输入给出可复现的纳入与排除理由。
- [ ] 分类裁剪继承父图 split，裁剪风险与逐对象纳入记录完整。
- [ ] VOC/COCO/YOLO 输出经独立解析，类别编号、框坐标与源几何一致。
- [ ] 用实际目标训练程序分别加载检测与分类样例；记录程序版本和使用配置，不以同一导出器回读替代。
- [ ] 训练包包含版本、规则、类别、划分、复核覆盖、组覆盖、排除清单和校验。
- [ ] 输出无真实身份字符串、源设备路径和原始文件名泄漏；图像仍需独立隐私复核。
- [ ] 构建新目录，失败不留下假成功包，旧训练产物不可被覆盖。

## 分发与公开站点

- [ ] 自动化检查通过，记录仍未完成的手工验收与训练加载验证。
- [ ] README、使用手册、页面按钮与真实功能一致，后续功能明确标注。
- [ ] Git 暂存/历史和发布包仅有代码、通用文档和合成资料。
- [ ] GitHub Pages artifact 仅为 `website/`，不上传仓库根或本地工作空间。
- [ ] Pages 设置选择 GitHub Actions，部署成功后核实实际网站 URL。
- [ ] 公开站点无医院资料、私有路径、身份表、个体文件哈希、令牌和远程跟踪脚本。
- [ ] 发行 ZIP/wheel 可下载并在干净环境复现启动；注明代码许可不等于数据许可。
- [ ] 未把本机 HTTP 服务描述为可直接开放公网的多人服务器。

## 后续范围

COCO/YOLO 输入、全部近重复自动发现、三折外层/内层向导、模型预标注、多边形分割、GitHub 真实数据上传、私有服务器认证和多人协作需要后续独立实现与验收。
