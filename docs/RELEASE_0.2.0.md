# 0.2.0：本地复核与训练包首版

新增本地浏览器工作台：导入 VOC/已有工作集、独立复制校验、原图和矩形框编辑、标签修订、问题备注、自动草稿、撤销/重做、完整性确认、版本化类别方案、身份 CSV 与确认来源关系、固定分组划分，以及检测/分类训练包。

两档导出使用相同的技术与来源门槛：严格档要求逐图人工确认与分类裁剪确认，基础档明确记录人工复核覆盖及探索限制。未知/ignore 对象默认整图暂缓，多主细胞裁剪不能通过单击纳入绕过。坐标解释需核对叠框与依据。公开网站和在线示例仅含几何合成资料。

## 验证记录

- Windows、Python 3.11.7、独立虚拟环境、Pillow 12.3.0：23 项合成数据测试通过，包括原始文件不变、坐标边界、分组泄漏、未知/忽略处置、持久化恢复、旧修订拒绝、取消、任务失败和真实训练输出。
- Edge 无头浏览器：框移动与新增、稳定对象 ID、标签修改、撤销/重做、软删除、保存失败与恢复、方案载入、划分确认、严格导出和 ZIP 下载通过；无页面脚本错误。
- 完整合成演练：12 张图、72 个分类裁剪，导出 VOC、COCO、YOLO 与分类包及报告。随后增加加载示例文件，具体文件数量以产物 manifest/校验清单为准。
- 已使用实际 Torch 1.8.1 / torchvision 0.9.1 的 VOCDetection 和 ImageFolder 读取三个集合，并形成分类张量批次。VOCDetection 测试采用 VOCdevkit/VOC2007 布局，year=2007；COCO/YOLO 使用独立格式解析及产物自带加载示例验证，尚未对全部训练框架逐一实测。
- 公开页面在 320/390/768/1440 宽度下检查无水平溢出；本地界面检查桌面和移动布局。

GitHub Actions 另外配置 Windows/Linux 与 Python 3.11/3.12 检查；最终通过状态以对应提交的 CI 为准。

## 已知边界

服务仅支持本地个人使用，不能直接开放公网；私有服务器认证、多人协作、真实数据远程发布、COCO/YOLO 输入、自动近重复搜索和外层/内层交叉验证向导尚未实现。

基础分组按完整连通组配置比例，不保证稀有类覆盖所有集合。身份未知的来源分量划分只能支持探索主张。截图演示不证明真实医院标注准确。任务取消在文件处理边界生效；取消/失败目录可能保留未注册中间文件以供诊断，不进入成功列表。

VOC 输出兼容常见加载器的 JPG，quality=100、subsampling=0，仍有 JPEG 转码损失；COCO、YOLO 和分类裁剪使用无损 PNG。所有格式保留原图尺寸。训练包移除图像元数据和私有路径，不代表图像像素已经脱敏，也不自动授予再分发权。

历史未经过本工作台的新坐标确认字段的快照保留兼容行为；新导入图像默认需要显式确认。真实数据必须按自身授权、标注和评估规则复核，不能直接套用合成示例的放行状态。
