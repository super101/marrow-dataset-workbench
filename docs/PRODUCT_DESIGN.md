# Marrow Dataset Workbench 产品设计方案 v1

状态：设计基线，复核流程已按 [0.2.1 调整说明](RELEASE_0.2.1.md)更新；早期交付记录见[0.2.0 发布记录](RELEASE_0.2.0.md)，当前操作见[使用手册](USER_GUIDE.md)。本文同时保留后续设计。首版重心是产出可训练且可追溯的数据集。早期交互原型使用合成对象；正式本地工作台支持真实入库、持久化与训练包构建。

## 1. 产品目标与用户

面向个人科研人员，将已有显微图像和矩形标注整理为经过检查、复核、有固定类别方案与分组划分的检测和分类训练包。保留后续多人协作扩展位置，首版协作空间标注“敬请期待”，不收集用户信息。

主任务：导入资料 → 检查异常 → 逐图复核 → 固定类别映射 → 分组划分 → 冻结版本 → 生成训练包。以整张图为复核单位，支持按问题和单细胞跳转；裁剪与原图联动。

成功标准：研究者能说明每个训练文件来自哪张原图、哪次修订、哪个类别方案、哪个分组和划分；训练程序能正确解析输出；排除和未解决事项可查。页面漂亮、文件能下载均不单独构成成功。

## 2. 运行与公开发布

| 形态 | 功能与边界 |
| --- | --- |
| 公开官网 | 产品介绍、合成数据演示、下载、安装、文档、GitHub 反馈与贡献入口；可用 GitHub Pages |
| 在线合成演示 | 体验看图、改框、直接完成复核与导出检查；默认无真实样本。浏览器内真实文件体验属于后续能力，上线前单独验收无上传 |
| 本地完整版（首版） | 本机启动服务，通过浏览器访问；只读取用户选择的数据根目录，工作数据与导出在仓库外 |
| 私有服务器（后续） | 复用界面/API；部署前提供认证、权限、TLS、访问日志、备份与存储范围设置；不能把仅绑定 localhost 的个人服务直接开放公网 |

“导入”表示复制到工作空间；“发布”表示向外部目的地传输，两者独立。下载代码不接触医院资料。公开网站不默认加载分析脚本、远程字体或第三方数据处理服务。

## 3. 首版范围与后续范围

首版必须：VOC 图像/XML 和字典 CSV 导入、独立复制和校验、检查队列、原图/框/裁剪、矩形框编辑、标签修订、问题与备注、自动草稿、复核状态、类别映射版本、身份映射 CSV、分组与自定义比例划分、两档导出、VOC/COCO/YOLO 检测输出、单细胞分类输出、审计与统计、可安装运行说明、合成演示。

后续：COCO/YOLO 输入适配、多边形/分割、模型辅助建议、近重复候选自动发现、三折外层和内层清单向导、GitHub 真实数据发布、私有服务器部署、多人冲突处理。首版不安排训练模型、医学自动裁定或大语言模型自动标签。

线上演示可先于完整后端发布，但必须标为演示。完整功能按验收结果逐项标记，不能用原型中的按钮暗示已完成。

## 4. 信息架构

- 数据集：总览、入库向导、浏览与复核。
- 导出与发布：训练包配置、导出检查、任务进度、历史产物。外部发布首版展示规划说明。
- 协作空间：敬请期待。
- 高级：类别方案、身份与分组、划分、来源与规则、版本与审计。默认收起；必需技术配置与选填说明分别提示。

首页突出“继续上次复核”。首次使用显示“打开已有工作版本”和“导入新数据”，无数据时不展示虚构统计。

### 首页内容

顶部：当前数据集、工作分支/版本、最近草稿状态。

统计：图像文件数、不同图像内容数、有效/全部框数、训练类别数、待复核图像数与问题数分别计算。重复文件、派生裁剪不算新增独立样本。

问题队列：未知类别、结构/框错误、重复标注冲突、争议对象；点击即筛选原图列表。完整性记录缺失在报告中提示，不妨碍完成复核。类别分布默认按原始编码统计，可切换训练类别；显示实例数、图像数、已证实组数。

训练准备：来源使用依据、标签方案、复核覆盖、分组、划分、导出适配六项状态，不汇总成容易误解的“医学合格分”。

## 5. 入库向导

1. 选择来源：本地目录或单独选择文件，首版优先 VOC 的 JPEGImages/Annotations 结构。显示识别到的文件、格式、大小，异常文件不静默丢失。
2. 标签字典：导入 code/name/role CSV，编码保留字符串；未知编码列为 unresolved。网页允许为缺失编码补充定义和依据，不猜名称。
3. 来源与规则：记录提供方、版本、获得日期、研究/共享/公开展示权限、伦理适用情况、历史实验使用。依据状态 verified/pending/not_permitted；依据文件存受控本地位置。
4. 坐标约定：必须显式选择源格式为零起点半开区间或一开始点闭区间，显示第一张框叠加确认。VOC 文件名不自动证明坐标约定。
5. 输出位置：独立新工作目录；拒绝源目录、嵌套源目录、覆盖旧版本和硬链接替代。估算图像、缩略图、草稿和导出的共存空间。
6. 执行：可观察进度、成功/失败清单、中止状态；任务失败不标记入库成功。逐文件复制和哈希校验，重新读取验证工作副本；源快照不等于修改源目录权限。

## 6. 浏览与复核页面

桌面三栏：左侧图像队列约 20%，中间原图约 55%，右侧对象详情约 25%。工具栏保留上一张/下一张、筛选、选择/画框、缩放、框显隐、撤销/重做。窄屏改为原图优先，列表和详情可折叠；精确框编辑建议桌面使用。

左栏：缩略图、ID、框数、问题数、复核状态；按类别、问题、状态筛选。提供“只看待复核”和“下一处问题”。翻页/虚拟列表避免一次解码所有原图。

中栏：原图、矩形框、类别文字；选中框突出，其余降低强度。点击选中，拖动移动，四角/边拖动缩放，画框新增。边缘细胞只标提示，不自动删。背景图加载失败给出重试和文件检查入口。

右栏：选中细胞裁剪、原始标签、当前标签、训练类别、框坐标、截断/困难标志、对象问题和选填备注。支持改类、改框、增加框、直接软删除；不弹出必填理由表单，删除可撤销。未知或争议可以保留待解决，也可由操作员决定删除或排除整图；自动历史保留操作，软件不补造依据。

本图类别数量随有效修改更新；数据集总量在服务端接受修改后更新，并注明统计范围。无框图和标注完整性未知情况在报告中提示，是否作为可靠负样本由研究者判断，不用必填勾选代替判断。

### 自动草稿与撤销

修改后约 800ms 防抖提交，关键动作立即写入。显示“有未保存修改/保存中/已保存/保存失败”。服务端确认事务提交后才显示已保存；本地缓存只是失败恢复候选。保存失败可重试、导出恢复草稿，禁止无提示关闭。草稿在重新打开数据集后恢复。

每张图有撤销/重做栈；每次服务端修订分配单调递增 revision，使用乐观锁避免多标签页覆盖。编辑已确认图立即撤销其确认状态，待重新复核；修改类别方案、身份或划分会使关联导出检查失效。

### 状态与问题

图像复核状态：未查看 → 复核中 → 已复核；另有已排除。整图可排除并恢复。已复核状态与问题清单并存，不代表问题消失。

问题通过备注和检查结果展示；未来可扩展开放、已处置和待外部确认等状态。操作时间、修订和对象变化自动记录，操作者补充的理由及依据选填。技术检查根据实际数据重算；重复冲突仍需统一标注或排除相关图，复核状态不修改实际框和类别。

“完成复核”一次点击即保存当前修改并记录复核决定，不需要额外勾选完整性、填写理由或消除问题。保存失败仍提示重试，版本冲突仍需核对。严格的操作员要求属于外部科研和组织流程；软件提供提示、历史与导出技术检查，不通过表单重复执行人员制度。

## 7. 类别方案

三层分开：原始标签（不变）→ 人工修订标签（保留历史）→ 训练类别映射（版本化）。原始定义错误不原地改写。

方案支持保存多份，如细分类、合并分类。字段：原始/修订编码、名称、角色、训练名称、处理方式、合并依据、数量、图像/组覆盖。处理方式 cell/ignore/unresolved/out_of_scope；任务定义和合并依据可记录，未记录时报告提示，软件不猜测未知类别的含义。

导出时按冻结顺序产生连续整数 ID；内部类别表和 YOLO 用零起点，COCO category_id 用一开始点，VOC 的 name 写训练类别名称，并提供跨格式对应表。空类/禁用类不改变已经冻结产物。修改方案另建版本。

## 8. 身份、关系与划分

导入 image_id、patient_id、slide_id、acquisition_batch_id、source_image_id、metadata_evidence 等 CSV；依据文本选填，身份真实性由研究者核实。同玻片映射不同患者属于冲突。编号/时间只能写在代理敏感性字段。

分组使用连通分量：共享患者、共享玻片、已确认来源、完全重复、经人工确认的重叠/近重复关系都不能跨集合；即使部分患者字段缺失，也保留已知约束。source_image_id 指向另一条记录时与该记录连接，而不是只匹配同字段字符串。批次默认用于分布分析，不自动等同患者。

选择模式：患者独立（要求完整可靠身份）、玻片独立（声明范围）、来源分量探索（明确患者独立性未知）。身份缺失可以探索，不伪造独立性。检测不到近重复不等于没有近重复。

用户设置比例/组数和随机种子；不固定套用某个比例。预览真实组数、最大组、每类跨组覆盖和分布，确认后封存。仅单组出现的类别标明跨组效果无法可靠估计，不拆组保证覆盖。无可行划分时阻断，不伪造平衡结果。

三折外层/内层向导后续实现；首版支持导入外部预定义 fold 清单并进行组泄漏检查。历史用于开发的样本不因改名为 test 就成为真正未见数据。

## 9. 两档导出与提示

| 条件 | 已复核版 | 基础检查版 |
| --- | --- | --- |
| 图像/XML、框、类别、文件完整性 | 必须通过 | 必须通过 |
| 逐图复核状态 | 选择已点击“完成复核”的图 | 允许未逐图复核 |
| 完整性、依据与问题备注 | 选填并如实报告，不阻止导出 | 同左 |
| 当前有效对象的未知类别 | 修订为可输出类别或排除相关图 | 同左 |
| ignore 对训练器的支持 | 首版默认排除含此对象的整张图 | 同左 |
| 分组与泄漏检查 | 必须 | 必须 |
| 身份范围 | 按证据声明，可为探索 | 同左 |
| 研究使用状态及说明 | 原样保留，缺失或待核实时提示；研究者判断用途 | 同左 |
| 复核覆盖率与限制 | 必须报告 | 必须报告，显著标记探索用途 |

两档保留格式、几何、源文件和划分技术检查；已复核版表示按复核状态筛选，不表示医学认证、穷尽标注或获得使用许可。操作说明与使用依据不设必填，未记录事项如实进入提示。导出只针对预览中纳入的子集检查，排除记录完整保留。

默认无法表达 ignore 的普通训练器，含有效 unresolved/ignore 对象的整图暂缓；问题备注本身只作提示。COCO 的 iscrowd 和 VOC difficult 不通用地等价于 ignore，不自动互转。out_of_scope 对象按当前任务规则作为任务外处理；任务说明选填并进入报告。删除对象不再监督训练，删除理由不作为导出门槛。未来接入验证过的忽略损失和评估适配器后可单独放行。

每次构建前重新核验工作图像内容、修订、映射、分组/划分和规则版本；通过才进入生成。操作中断不留下看似成功的半成品包。

## 10. 训练包与格式

### 检测输出

- VOC：JPEGImages/、Annotations/、ImageSets/Main/train.txt、val.txt、test.txt。按导出约定写入坐标，明确一开始点闭区间转换；不复制原 XML 的设备路径。
- COCO：images/{split}/ 与 annotations/instances_{split}.json；bbox 为零起点 [x,y,w,h]，area 明确为框面积，iscrowd 默认 0；ID 在包内唯一。
- YOLO：images/{split}/、labels/{split}/、data.yaml；框中心/宽高归一化，类别为零起点；不支持的语义不能悄悄丢弃。

内部统一坐标是零起点半开区间 [xmin,ymin,xmax,ymax)，合法范围 0≤xmin<xmax≤W、0≤ymin<ymax≤H。转换示例：VOC 一开始点闭区间 [1,1,10,10] → 内部 [0,0,10,10]；导出回 VOC 为 [1,1,10,10]。整数化与裁剪规则写入 manifest，不重复四舍五入积累偏移。

### 分类输出

先分组划分原图，再裁剪；所有细胞继承父图 split。默认保留原分辨率裁剪，不强制改变细胞纵横比，训练时 resize 由使用者决定。上下文比例为可配置项，初始为 0%，冻结进规则；不能按测试成绩调裁剪参数。

结构为 classification/{train,val,test}/{class_id}/。每个文件在 crops.csv 记录 parent_image_id、object_id、类别、原框、实际裁剪范围、父版本、split、可见性/截断标志和纳入决定。

候选裁剪检查：越界、最小尺寸、触边截断、多个主细胞和相邻框重叠提示。基于已有框的检查不能证明不存在漏标细胞。分类包已复核版要求明确选择裁剪纳入，基础档可沿用几何规则，列出覆盖率与限制。触边/截断样本可明确纳入，无须理由；多主对象裁剪仍暂缓分类输出。分类排除不必排除其检测父图，两个任务分别给出纳入清单。

### 所有训练包共同内容

dataset-card.md（来源/任务/范围/历史使用/限制）、classes.csv/json、split.csv、group-coverage.csv、excluded-images.csv、excluded-objects.csv、review-summary.json、rules.json、manifest.json、校验和清单、格式加载示例。

manifest 固定 dataset_version、revision、mapping_version、rule_version、split_version、构建工具版本、输入摘要、创建时间和输出摘要。私有可追溯清单和公开可分发卡片分离；不把真实身份/医院设备路径写入公开训练包。默认随机研究 ID/包内稳定 ID 不等于已经完成图像脱敏。

## 11. 导出页面与任务

四步：

1. 选择当前已保存版本、训练类别方案、已复核版/基础检查版。
2. 选择检测格式（可多选）与分类包、已有划分、分类裁剪规则。
3. 导出检查：按任务展示可纳入/排除图像和对象、逐集合分布、单组类限制、人工复核覆盖；点击问题回到原图。展示导出的随机样例和坐标叠加。
4. 冻结快照并构建：不可变产物、新目录、进度、取消、错误重试、成功校验、下载/打开位置。

成功后显示“导出成功”和实际产物清单。不能在点击按钮时就宣称已成功。再次构建使用新的构建 ID；不得覆盖已用于实验的旧包。

## 12. 上传与发布（后续设计保留）

目的地分为 GitHub（显示所有者/仓库/公开或私有）、私有服务器、仅生成本地分发包。数据发布前需核实研究使用、再分发、公开展示三项依据；签署隐私协议不自动替代数据提供方的公开授权。

发布预检：图像可识别信息、EXIF/嵌入元数据、XML path/source 字段、文件名、CSV 自由文本和身份映射；缩略图/裁剪同样检查。像素中的文字需要人工确认或经验证的流程；自动扫描不保证完成脱敏。

显示精确文件清单、体积、目的地、可见性、许可、排除项、不可逆传播提示；用户点击最终发布后才传输。大文件策略依据当时平台限制配置，不直接将整批图像加入 Git 历史；可选择经授权的受控数据存储并只发布引用清单。令牌仅存服务端安全凭据区，不写页面、导出包或仓库。

## 13. 技术结构

建议本地完整版：React + TypeScript + Vite 界面；FastAPI + Pydantic 接口；SQLite WAL 保存实体与修订；Pillow 负责缩略图和裁剪；文件系统保存不可变输入/构建产物。官网可单独静态构建。技术选择可在实施时根据依赖和打包成本调整，语义约束不变。

主要实体：Dataset、SourceAsset、Image、Object、Revision、ReviewIssue、ReviewDecision、LabelDefinition、MappingScheme、ProvenanceEdge、IdentityEvidence、SplitPlan、ExportBuild、UsePermission。Object 有稳定 ID，新增不会因为排序改变旧对象 ID。

本地服务默认只绑定 127.0.0.1，启动生成会话密钥，校验 Host/Origin，限制导入/读文件到登记根目录，拒绝路径穿越和符号链接逃逸。输入文字仅显示，绝不拼接执行。文件名/标签/备注按文本渲染。首版不提供任意服务器路径读取的公开 API。

长任务在后台队列串行/有限并发执行；CPU/IO 足够，无需 GPU。图像按需解码，缩略图分级缓存，原图进入视口再加载；不将整批原图 base64 塞入首页。先支持 Windows，提供 Python 启动脚本与故障说明，再补 Linux/macOS 包装。

接口方向：datasets/import、images（分页/过滤）、images/{id}/revisions、issues/{id}/decisions、mapping-schemes、identity-imports、split-plans/preview、export-checks、export-builds、jobs/{id}。所有修改含 expected_revision，失败可重试且不重复新增对象。

备份包含数据库与引用的工作资产；自动草稿不等于备份。恢复验证修订和文件一致性。身份对应表可位于单独受控目录，公开构建不包含它。

## 14. 开发顺序与验收

| 阶段 | 交付 | 完成条件 |
| --- | --- | --- |
| 设计基线 | 本文与合成交互原型 | 页面、状态与导出规则可评审 |
| 核心复核 | 读取已有工作集、编辑、问题、持久化 | 重启恢复，原图/XML 不变；改已确认图会回退状态 |
| 训练输出 | 映射、身份/分组、固定划分、两任务导出 | 实际训练加载器能读取；转换坐标正确；同源不跨集合 |
| 可分发首版 | 安装包/启动说明、公开合成演示、文档 | 新环境可复现启动；公开文件无真实资料；清楚标记未实现项 |
| 扩展 | 外部发布、私服与协作 | 独立验收授权、认证、凭据和传输行为 |

不预报未经验证的工期；以上按可验收产物推进。首版发布的关键门槛是能产出正确的真实训练文件，不是原型上线。

### 必须通过的行为验收

1. 源目录每个文件字节保持不变；输出为独立文件。
2. 图像缩放/拖动后的框在原始坐标系保存；坐标转换覆盖边界和单像素对象。
3. 自动保存失败、重启恢复、撤销和重复请求不丢修改；原始编码始终可查。
4. 改映射/框/身份后旧检查失效；被冻结导出仍保持原样。
5. 无完整性勾选、空备注或保留问题时均可完成复核；软删除可撤销且无必填理由，历史保留。不支持忽略时，含有效 ignore/未解决对象的整图暂缓导出。
6. 相同患者/玻片/来源和重复关系的传递闭包均同 split；只出现于一个组的类不会拆组。
7. 分类裁剪继承父 split；裁剪清单能反查稳定对象 ID；多细胞风险不默默通过。
8. VOC/COCO/YOLO 包经独立解析与样例加载验证；类别对应与几何一致。
9. 两档导出对相同输入给出可复现的纳入理由，统计与实际文件数一致。
10. 文件名、XML 内容、标签及备注包含恶意文本时不能执行；公开演示无真实数据、身份表或私有路径。

## 15. 原型覆盖与限制

原型覆盖总览、入库、三栏复核、类别方案、分组预览、导出门槛与规划页面。可以切换页面、选择细胞、拖动/调框、改类、标记问题、体验确认状态及输出检查变化。全部例子为明确命名的合成对象，不显示虚构医学名称。

原型不连接真实数据，不持久化完整标注，不完成真实导入、身份解析或训练包构建；其中“草稿”仅为交互状态演示。技术验收从后端与真实格式实现阶段开始。
